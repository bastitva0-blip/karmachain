# KarmaChain — Claude Code rules

Full spec: `prompt.md`. Work one phase at a time.

## Operating rules
1. Work phase by phase. Don't start a phase until the previous one's acceptance criteria pass. After each phase: run checks, commit, print a short report (built / how to run / stubbed).
2. Plan first for any phase touching more than 3 files.
3. **No scope creep.** Out-of-phase work gets `// TODO(phase-N)`. Never add The Graph, IPFS/Arweave, Chainlink, Kubernetes, or a message queue.
4. Verify external APIs against current docs before coding against them. Record each confirmed fact in `docs/VERIFIED.md` with a link.
5. Free tier only (except NVIDIA API and Railway). Every external call: timeout, retry with backoff, cached or fallback path.
6. Secrets never reach the browser. NVIDIA, ElevenLabs, GitHub secret, signer keys live only in `apps/api`. Repo has `.env.example`, never `.env`.
7. User-supplied content (code, PDFs, pages, transcripts) is untrusted. Delimited data blocks in prompts, strict JSON output, zod validation. LLM output never decides security-relevant things alone.
8. Small conventional commits (`feat(api): ...`). At least one commit per phase.
9. Boring, readable TypeScript. Strict mode. No `any` without a comment.
10. Blocked > 10 min: stop and ask with two options + a recommendation.
11. Never write "mathematically impossible" anywhere. SBTs stop buying reputation, not farming it.

|---|---|
| Monorepo | pnpm workspaces: `apps/web`, `apps/api`, `packages/contracts`, `packages/shared` |

| Backend | Node 20+ + Hono + zod |

| DB | Neon/Supabase Postgres + Drizzle |
| Vectors | jsonb float arrays, cosine in TS (no pgvector) |

| Voice | ElevenLabs Agents, Scribe, TTS |
| Auth | GitHub OAuth in API; web proxies `/api/*` to API via Next rewrites (first-party cookies) |

| Gas | Backend relayer pays mints; testimonials via EAS delegated attestation |

## Commands

- `pnpm dev` — web :3000 + api :8787
- `pnpm typecheck` / `pnpm lint` — all packages
- `pnpm test` — all tests
- `pnpm --filter contracts test` — Foundry tests (Phase 1+)

## Conventions
- `packages/shared` exports TS source directly (`@karma/shared`); web uses `transpilePackages`, api runs via `tsx`.
- TypeScript pinned to 6.0.x (typescript-eslint doesn't support 7 yet). ESLint pinned to 9 (Next plugins don't support 10).
- Next rewrites resolve `API_INTERNAL_URL` at **build time**. On Railway, set it for the web service's build too (e.g. private-network URL of the api service).
- `apps/web/AGENTS.md` + `apps/web/CLAUDE.md` are auto-generated by `next dev`; read `apps/web/node_modules/next/dist/docs/` before writing Next code.
- UI follows `docs/design/DESIGN.md` (tokens, type, "The Seal" logo in `apps/web/src/components/brand/Logo.tsx`); mockups in `docs/design/screens/`. Every "OTHER STATES" strip is a real state in code.
- Git Bash rewrites args starting with `/` into Windows paths (MSYS). Set `MSYS_NO_PATHCONV=1` before `railway variable set` with path values like `NEXT_PUBLIC_API_BASE=/api`.
